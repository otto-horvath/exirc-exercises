Classic IRC, browser-native

One window. Every conversation.

Dense, keyboard-first, and built around server events. This mock shows one path through the interface without opening a socket.

  • Alt + 1…9 jump to a tab
  • Alt + ←/→ cycle tabs
  • Tab completes nicknames in the composer
  • Enter sends; Shift + Enter adds a line

Nickname required. Server and NickServ passwords live under advanced options, where they belong. Nothing is stored or sent.
